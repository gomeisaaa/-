# V3 审查、实施方案与阶段记录

## 范围与发布

需求来源：用户《她的缓冲区》V3.0 网页改版开发需求书。
审查基线：d4ff6fe，已核对本地与远程 gh-pages 一致。
保持纯静态网站、三种配色、圆角风格、0–3项微行动、零任务休息及点击鼓励。
阶段一尚未完成，不更新现网为 V3；本次提交仅包含未接入页面的基础模块、测试和计划。

## 审查结论

- app.js 统一管理路由、DOM字符串渲染及事件代理；旧自查入口、结果及历史耦合，需要逐一替换，不能只换标题。
- assessment.js/questions.js 是原创题目与九维度描述分；不能与 PHQ-9 数据转换、求和或混画。
- storage.js 的旧日志与摘要保存在两个 localStorage v1 键；读写均有90条截断。后续V3事件存储不沿用此隐式淘汰逻辑。
- cycle.js 保存实际出血日期，支持开始日间隔的日期估算；尚无周期位置曲线、相邻周期比较或阶段未知选项。
- 当前无照片、收藏、IndexedDB；CSP img-src尚不允许blob，接入图片时只增加本地blob权限，继续保留 connect-src 'none'。
- 旧版清空功能不了解未来备份/照片数据，需要统一删除清单及可失败的独立存储清除流程。
- 旧测试覆盖行动、日期估算与原创自查，不构成PHQ-9或照片验收。

## 四阶段实施方案

### 阶段一：基础数据、PHQ-9和安全

先建立只增不改的原始备份及版本标记。V3事件读取旧记录时以原键为只读来源，不修改或删除原值；异常数据保留原字节并提示。完整清除须包括敏感备份。

PHQ-9正式中文题目需逐字对照可追溯版本，记录题目来源、语言及版本。使用独立模块、独立历史键、独立结果页；九题全部回答才有0–27总分。第9题>0时优先专业求助，若主动报告立即危险则进入即时帮助；不自动推断风险等级。14天是产品提醒策略，按最近完整评估计算，允许自愿提前重测。回答默认只在内存，主动保存才写入本地。

预计变更：新增 phq9-scoring.js、versioned-data.js、来源文件、PHQ页面模块；接入 app.js、index.html 和文案；保留旧模块以读取/验证旧记录，但移除其正式测评入口。

验收：28种总分、各阈值、缺题、稀疏数组、非法值、第9题低总分、即时危险、14天与跨月、重复测评、异常数据、配额不足、旧数据不变、历史隔离、删除。结果页截图包含普通与安全提示两种情况。

### 阶段二：周期日历和情绪事件

V3事件独立带版本：id、timestamp、emotion、mood(-3..3)、title、note、eventTag。旧事件以稳定id只读适配，编辑前创建V3副本并记录legacyId，隐藏映射与数据一同版本化；删除旧事件需用户明确操作，不因迁移删除。

日历支持月切换、空白日期、补记及同日多次记录。默认主推周期视图，仍可切换日历和历史比较。每日聚合采用当天最后一条记录，日内明细保留全部；历史比较按实际周期开始日计算相对天数，保留具体日期，缺失不补零、不跨缺口连线，周期长度不同不归一化。无经期信息仍可记录。

周期状态提供“未知/不适用”选项（不规律、激素避孕、妊娠/哺乳等不强推断）。只显示实际出血窗口和有条件的日历估计；不能可靠估计时明确告知。说明出血期与卵泡期重叠、排卵/激素无法仅凭日历确认，以及科研、工作、睡眠等共同背景。

验收：多事件/正负混合、月界闰日、编辑删除、阶段未知、同日聚合、不同长度周期、缺口、少数据；手机日历/曲线截图。

### 阶段三：照片和温暖记忆

初期每事件1张照片。接受JPEG/PNG/WebP，原文件上限10MB，解码尺寸上限约2000万像素，缩放至最长边1600px并重新编码JPEG/WebP，丢弃原EXIF。格式不支持或文件过大时明确提示（HEIC提示转JPEG，不假装兼容）。图片保存IndexedDB，与V3事件在同一数据库事务中写入，避免只保存一半；拒绝隐式淘汰。用户主动选择、预览、更换、独立删除；配额异常保留旧记录并显示未保存。

收藏是事件上的可独立取消标志；仅从用户收藏且存在的积极事件随机回顾，明确同意后展示。支持今天不看、换一条、关闭/不再推荐、取消收藏、删除及感受评价；“更难受”立即停止推荐。第9题提示/即时帮助优先，不弹积极回忆遮挡。PHQ结果须用户同意才展示周期背景，不改变分数。

验收：压缩与无EXIF、0/1张、拒绝格式/大小/像素、刷新恢复、换图失败保留旧图、配额耗尽、事务回滚、取消收藏不删事件、空库不编造、负反馈停止、全部清除包括备份。图片及回忆截图只使用合成测试数据。

### 阶段四：首页、兼容性与交付

首页主入口改为周期情绪记录，独立PHQ-9和行动入口。更新介绍、数据告知及各数据保留规则，保留三色主题。补齐Android Chromium与iPhone尺寸/WebKit引擎自动化；模拟不等于实体机，需要明确报告实机未测。CSP及请求监听检查应用未上传数据。

每阶段独立提交，报告文件、算法/存储、通过/失败/未测、限制及截图。部署前运行全部回归；上线与GitHub部署成功分别核验，无法访问不能宣称成功。
